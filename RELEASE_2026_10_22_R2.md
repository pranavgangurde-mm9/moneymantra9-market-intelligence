# Version 2026.10.22-R2 — Changes

## Issues addressed

1. **Gold NaN / XAU legacy pane:** restored India-focused benchmark and protected all number formatting against invalid values; removed XAU/USD as the price basis.
2. **NSE stock search:** requests the official main-board equity directory as a CSV from Cloudflare; full search list when source is available; on-device saved list if refresh is blocked; optional Cloudflare KV and daily Cron pre-warming.
3. **Historical observation log:** retrieves 20 completed session closes for each selected NSE stock or Nifty, independently of the browser's observation history. Dynamic SVG line chart, pointer/tap/readout, and CSV export. No unsupported claim of historic signal accuracy.
4. **Charts:** point inspection for Nifty session trend, historical closes and sector intraday mini chart.
5. **Radar:** unavailable prices and sector breadth display unknown instead of bearish, score shows missing when Nifty source is missing; unchanged score shows 'Pulse unchanged'.
6. **Finance AI:** sends selected stock/current app context and recent chat turns to the Worker; backend answers gold/silver Indian-rate questions from a real India benchmark if available, shows its date, and supports basic purity/weight multiplication. New chat/Clear removes previous local chat history. Responses remain concise.
7. **Reports:** separate Current Brief/Closing Report preserved; Copy and WhatsApp dialog added with optional mobile number; opening WhatsApp never sends a message without user confirmation.
8. **Build identification:** internal HTML metadata includes `2026.10.22-R2`; the mobile header remains uncluttered.

## Test coverage performed before packaging

- Node JavaScript syntax checks of frontend and Worker.
- Headless Chromium mobile UI under mocked Cloudflare market, NSE-directory, gold/silver, sector and Finance AI endpoints: loaded, 1100+ sample directory, 20-of-20 historical chart, selected stock, daily frame, gold/silver without NaN, sector chart opened, Finance AI answer, new chat, report share dialog, zero page JavaScript exceptions.
- Node Worker tests under mocked upstream NSE official CSV, Yahoo chart, and Indian bullion benchmark: `/health`, `/api/symbols`, `/api/india-metals`, `/api/gold`, `/api/silver`, `/api/pulse`, `/api/market`, and `/api/ask` (gold, silver, finance concept) all returned success.
- **Not performed:** deployment to the user's Cloudflare/GitHub accounts, real publisher response tests, real WhatsApp app end-to-end send, or live exchange verification. Those depend on external services and the user's account.
